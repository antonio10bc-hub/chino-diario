# Instrucciones para Claude

- Web estática sin build: `index.html`, `styles.css`, `app.js`, `words.json`. Vercel despliega desde `main`.
- Al terminar un cambio, haz commit y push a la rama de trabajo y también a `main`.
- Estilo: minimalista, papel/tinta/sello rojo. Las palabras nuevas se añaden al final de `words.json` para no alterar el orden de los días pasados.
