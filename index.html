    小组件 widget en el iPhone

    1. Instala Scriptable (gratis) desde la App Store.
    2. Pulsa Copiar script aquí abajo.
    3. En Scriptable, pulsa +, pega el código y llámalo Chino diario.
    4. En la pantalla de inicio, mantén pulsado → + → Scriptable → tamaño grande.
    5. Mantén pulsado el widget → Editar widget → Script: Chino diario.

    Para tener la app: en Safari, botón compartir → Añadir a pantalla de inicio.
